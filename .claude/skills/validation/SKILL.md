# validation

Use after code edits or before declaring a task complete.

## Rules
- dev: `npm run dev`
- build: `npm run build`
- test: `npm run test`
- lint: `npm run lint`
- typecheck: `npm run check`
- Run the narrowest relevant command first.
- If validation cannot be run, report the exact reason.
